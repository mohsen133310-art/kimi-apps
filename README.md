# Kimi Apps

وب‌سایت فارسی و راست‌چین برای معرفی و دریافت برنامه‌های Kimi Apps.

## امکانات
- نمایش برنامه‌های منتشرشده از Supabase
- جست‌وجو و فیلتر دسته‌بندی
- صفحه جزئیات هر برنامه و لینک APK / نسخه وب / GitHub
- ثبت دیدگاه و پاسخ بدون حساب کاربری
- انتشار فوری دیدگاه‌ها و پاسخ‌ها
- طراحی واکنش‌گرا با تم سفید و بنفش

## راه‌اندازی
این پروژه یک سایت استاتیک است. فایل اصلی `index.html` را می‌توان با GitHub Pages میزبانی کرد.
در GitHub وارد **Settings → Pages** شوید و در بخش Build and deployment، گزینه **GitHub Actions** را انتخاب کنید.

## مدیریت و انتشار برنامه (فقط مدیر)
برای حفظ امنیت، پنل مدیریت عمومی در سایت قرار داده نشده است. برنامه‌ها را از پنل Supabase مدیریت کنید:

1. وارد [Supabase Table Editor](https://supabase.com/dashboard/project/rrcalskgqqkclogvjsyv/editor) شوید.
2. جدول `public.apps` را باز کنید و **Insert row** را بزنید.
3. حداقل فیلدهای `slug`، `title`، `description`، `category`، `version` و `apk_url` را تکمیل کنید.
4. برای نمایش عمومی، `is_published` را `true` قرار دهید. برای پیش‌نویس، `false` باشد.
5. برای ویرایش یا حذف، همان ردیف را در جدول تغییر دهید.

### فیلدهای جدول apps
- `slug`: شناسه یکتای انگلیسی و بدون فاصله، مانند `kimi-notes`
- `title`: نام نمایشی برنامه
- `description`: توضیحات
- `category`: دسته‌بندی
- `icon_url`: لینک مستقیم تصویر آیکون
- `screenshots`: آرایه‌ای از لینک تصاویر (گالری در نسخه فعلی فعال نشده)
- `version`: شماره نسخه
- `apk_url`: لینک مستقیم فایل APK
- `web_url`: لینک نسخه وب
- `github_url`: لینک مخزن GitHub
- `is_published`: انتشار عمومی یا پیش‌نویس

## نکته امنیتی
کلید Publishable داخل کد مرورگر قرار دارد و برای دسترسی عمومی طراحی شده است. هرگز کلید `service_role` یا کلیدهای Secret را در این مخزن قرار ندهید. امنیت داده‌ها با RLS و policyهای Supabase اعمال می‌شود. دیدگاه‌ها و پاسخ‌ها بدون بررسی مدیر فوراً منتشر می‌شوند؛ در صورت افزایش اسپم، CAPTCHA یا محدودسازی ارسال را اضافه کنید.
